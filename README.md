# trabalho_embarcados_22_10_26

1. Controle de servo motor com potenciômetros
Montamos um circuito com dois potenciômetros: um para definir o ângulo do servo motor e outro para ajustar a velocidade do movimento. Ao final, conseguimos controlar tanto a posição quanto a velocidade corretamente.
2. Alarme com sensor LDR e laser
Montamos um sistema com um laser apontado para o sensor de luminosidade LDR. Quando alguém interrompe o feixe, o Arduino detecta a diminuição da luz e aciona uma sirene no buzzer. Ao final, o sistema detectou a interrupção e disparou o alarme corretamente.
